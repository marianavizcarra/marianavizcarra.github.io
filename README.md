# Portfolio — Mariana Castellanos Vizcarra

Personal portfolio site for a data analyst, built as a static page (no framework, no build step) and hosted on GitHub Pages.

**Live:** `https://<username>.github.io/github_pages/` (or `<username>.github.io` if served from a `<username>.github.io` repo)

## Stack

- Plain HTML + CSS + a few lines of vanilla JS (scroll reveal, mobile menu)
- Zero dependencies, zero build step — push to deploy

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deployment

Any push to the default branch is picked up by GitHub Pages (source: branch, root folder). No workflow needed.

## Privacy

Personal contact details (email, phone) are intentionally excluded. Contact happens via LinkedIn. `cv.pdf` is git-ignored.
